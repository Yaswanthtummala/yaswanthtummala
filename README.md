## 🚀 Featured Project

### 💳 [Fraudulent Financial Transaction Detection](https://github.com/Yaswanthtummala/fraud-detection-ml)
*MSc Dissertation · Teesside University*

An end-to-end ML pipeline that detects fraud in **5 million transactions** where only **3.59%** are fraudulent, from SQL database design to a deployed Flask web app.

| 🎯 Recall | 📈 ROC-AUC | ⚖️ F1-score |
|:---:|:---:|:---:|
| **0.69** *(from below 0.20)* | **0.93** | **0.51** |

- Engineered **11 behavioural features**; **8 of the top 10** model features were mine
- Applied **SMOTE** to training data only and tuned **91 decision thresholds** across **6 classifiers**
- Built a **Flask app** with **6 Plotly dashboards** and a live fraud-prediction page

**Tech:** `Python` `SQL` `pandas` `scikit-learn` `SMOTE` `XGBoost` `Flask` `Plotly`
